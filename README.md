Program ini digunakan untuk menghitung total biaya pemesanan kamar hotel berdasarkan jenis kamar dan lama menginap.

1. Function
Function digunakan untuk menghitung biaya kamar hotel. Function memiliki dua parameter, yaitu jenis_kamar dan lama_menginap.

2. Percabangan 
Percabangan ini untuk menentukan kamar apa yang di pilih apakah kamar standar atau kamar deluxe:

* Kamar Standard = Rp200.000 per malam.
* Kamar Deluxe = Rp350.000 per malam.

3. Perhitungan biaya
dan ini contoh harga untuk di totalkannya kaya di bawah ini:

Contoh:
Rp350.000 × 3 malam = Rp1.050.000

4. return
return ini untuk mengembalikan hasil biayanya function.
